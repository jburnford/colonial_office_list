## Common Over-extraction Patterns Across All Three Years

1. **Island Groups Over-extracted**: LEEWARD ISLANDS, WINDWARD ISLANDS consistently split with sub-islands as separate entries
2. **Duplicate Colony Headers**: Subsection headers within colonies treated as new colonies
3. **Gold Coast**: Consistently split across multiple entries
4. **Trinidad**: Consistently split across multiple entries
5. **Headers with Multiple Colonies**: Combined headers like "FALKLAND ISLANDS : FIJI" and "ST. HELENA : SARAWAK"
6. **Non-colony Entries**: Companies (FALKLAND ISLANDS COMPANY), Legislature bodies, Volunteer forces
7. **Table Headers Mistaken for Colony Starts**: BRITISH HONDURAS in 1948

## Methodology

For each year, the following manual LLM-based approach was used:

1. **Initial Analysis**: Run pattern recognition to identify potential colony headers
2. **Over-extraction Detection**: Compare initial extraction with OCR content to find:
   - Duplicate entries
   - Subsection headers treated as colonies
   - Non-colony entries (companies, legislatures, etc.)
   - Combined headers
   - Table headers vs. actual content starts
3. **Boundary Verification**: Read OCR source at identified boundaries to confirm:
   - Proper colony start (not subsection or table header)
   - Proper colony end (before next colony, not including it)
   - Merged subsections stay within single colony
4. **Script Creation**: Generate metadata and extraction scripts with verified boundaries
5. **Extraction**: Run scripts to create corrected output
6. **Verification**: Count files and verify output completeness

All boundaries were manually verified by reading the OCR source content at potential split points.
