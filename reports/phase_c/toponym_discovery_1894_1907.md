## Methodology

### Extraction Process

1. **Pattern-based extraction** using multiple regex patterns for:
   - Explicit location markers (in, at, of, from, to, near)
   - Geographical features (Mount, River, Lake, Bay, Island, etc.)
   - Administrative divisions (Colony, District, Province, Parish)
   - Settlement types (capital, headquarters, town, city)

2. **Context-based classification** to determine place types:
   - territory (colonies, protectorates)
   - administrative_division (districts, provinces, parishes)
   - city (capitals, towns, villages)
   - island (named islands and island groups)
   - water_feature (rivers, lakes)
   - mountain (named peaks and ranges)
   - port (harbors, bays)
   - geographic_feature (capes, peninsulas)

3. **Provenance tracking** with:
   - Source file name
   - Line number
   - Full context line
   - Total occurrences across sources

### Quality Criteria

- Proper names only (not generic descriptions)
- Historical spelling preserved
- Parent location context maintained
- Provenance with source line numbers
- Stopword filtering to exclude non-place terms
